# Security policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in the Publii desktop application, please email [contact@getpublii.com](mailto:contact@getpublii.com) with the subject `Publii security report`.

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

To help us investigate, include as much of the following information as possible:

- The affected Publii version and build number, and your operating system.
- A description of the issue and its potential security impact.
- Steps to reproduce the issue, including any relevant configuration.
- A proof of concept, screenshots, or logs, if available.
- Relevant source files or a commit reference, if known.

Remove passwords, access tokens, private keys, and personal data from any material you send.

We will review your report, request additional information if needed, and keep you informed of progress.

## Supported versions

Security fixes target the latest stable release of Publii. Where possible, check whether the issue also affects that release and include your installed version in the report.

## Coordinated disclosure

Please allow us a reasonable opportunity to investigate and address the issue before publishing technical details. We will work with you to coordinate public disclosure.

For general bugs and feature requests, use the [GitHub issue tracker](https://github.com/GetPublii/Publii/issues)
